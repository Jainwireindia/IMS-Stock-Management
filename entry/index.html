1 · Paste the production messages

2 · Chainlink and barbed wire (typed from the photos)

One line per item: machine, day / night, the name as it goes in the Excel, rolls and total kg. The wire is filled in for you and remembered. Type the kg of wire given from stock that day; only that is taken out of stock. Leave it blank or 0 when no new wire was given. A sum works too, e.g. 5.2+210.71-10.15.

Login and connection

You are logged in as . Logins (usernames, passwords, roles) are kept in the hidden USERS tab of the sheet. Logging out here also logs you out of the dashboard in this browser.

Production messages

How the messages are turned into the office Excel. Saved in the sheet, so every PC uses the same.

Sync report

A plain-text record of every call to the sheet: how long it took, timeouts, refused or failed saves, retries. Copy it and paste it where you need it. Reading it does not affect saving.

Category order

Drag a category, or use ↑ ↓, then save. The order is stored in the sheet, so every PC shows the same.

    How rows are written: only new rows are added after the last filled row of STOCK IN / STOCK OUT (columns A–E: Date, Product, Qty, Location, Type). Every save is listed in the TOOL LOG tab; the latest save can be undone from "Saves & undo" while it is still the last rows in the sheet. Other names of items live in the Varient and item finder tab (one row per product, names separated by ";"). You can add or correct them there by hand too; the tool picks them up on the next Refresh.
